CameraMod

Régler la vue et jouer à la première personne.

Comment l’utiliser

Utilise le zoom et les commandes de caméra du jeu pour choisir ta vue. Essaie l’équipement porté dans les vues rapprochées.

Comprendre la mécanique

Étend le comportement de caméra. Les modèles et accessoires peuvent masquer davantage la vue à la première personne.

Dans notre aventure

Utilise le zoom du jeu pour ajuster la vue. À la première personne, certains accessoires peuvent masquer une partie de l’écran.

Vue et personnage

Essaie la première personne avec ton équipement réel : un casque, une coiffure ou une morphologie inhabituelle peut masquer la vue davantage que le personnage de départ.
