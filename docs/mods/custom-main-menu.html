Custom Main Menu

WARGS dès le menu principal. La suite aura probablement moins de calme et davantage de sang.

Mode d’emploi

Lis les nouveautés du menu pour un aperçu du pack, puis lance la partie normalement.

Ce que ça change

Le menu porte l’identité WARGS. Les nouveautés donnent un aperçu de l’aventure, et le bouton du guide ouvre cette page dans ton navigateur.

Les règles du monde

Le bouton « Ouvrir le guide » ramène ici depuis le menu du jeu. Le texte d’accueil donne les repères de l’aventure.
