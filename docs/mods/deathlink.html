Deathlink

Tu es mort. Quelle surprise. Retrouve ce que ton profil de mort te prend, ce qu’il te laisse et ce que la compétence Deathlink permet de conserver.

Mode d’emploi

Choisis ton profil dans la fenêtre du mod et consulte son résumé dans le compendium. Avec Deathbound, après le respawn, ouvre ton inventaire pour choisir les pièces d’équipement que tu peux reprendre dans ta tombe. Le reste doit être récupéré sur place.

Ce que ça change

Avec Deathbound, la mort place les objets dans la tombe. Après le respawn, tu peux choisir des pièces d’équipement à reprendre, jusqu’à 4 avec la progression de Deathlink. Si tu portes déjà moins de pièces que le nombre autorisé, elles peuvent rester sur toi. Tuer, fabriquer, récolter et construire font progresser cette compétence ; les boss rapportent davantage.

Les règles du monde

Deathbound : perte de compétences de 5 % au départ jusqu’à 0 % à pleine maîtrise ; reprise de 0 à 4 pièces d’équipement. La nourriture est conservée par paliers de plats actifs, pas en rendant un pourcentage du temps de chaque repas. Aucun objet n’est détruit avec Deathbound.

La baisse annoncée 5 % → 0 % porte sur le niveau des compétences traitées ; la progression vers le prochain niveau peut être remise à zéro. La nourriture se conserve par nombre de repas, avec leur temps restant.

Deathbound ne détruit rien

Tes objets restent dans la tombe ou sur toi selon les règles de reprise. La compétence permet de choisir jusqu’à quatre pièces de matériel après le respawn ; elle ne sauve pas les matériaux, potions ou munitions directement sur toi.

Vérifier son profil

Les sept profils sont encore proposés. Certains peuvent détruire les objets non sauvés, voire le matériel. Consulte leur comparaison avant de choisir ; un changement depuis le compendium est autorisé.
