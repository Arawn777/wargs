My Little UI

Une interface plus pratique, sans prévisions ni production accélérée.

Les commandes utiles

Ctrl droit + clic : lien d’objet · Ctrl gauche + Alt gauche : inspection du chat

Retrouver tous les raccourcis ↗

Comment l’utiliser

Lis l’horloge en termes français plutôt qu’en heures exactes. Utilise Ctrl droit + clic sur un objet pour envoyer un lien dans le chat.

Comprendre la mécanique

Ajoute des panneaux et possibilités de présentation. Les changements de confort retenus n’accélèrent pas les temps de production.

Dans notre aventure

Horloge approximative en français, sans prévisions météo ni vent. La fabrication et les durées de production habituelles sont conservées par cette interface. Ctrl droit + clic permet de partager un objet dans le chat.

Le temps reste un repère

L’horloge donne une expression approximative en français. Elle ne fournit pas une prévision de météo ou de vent : observe le ciel et la saison avant de partir.

Partager un objet

Ctrl droit + clic sur l’objet prépare son lien dans le chat. Cela permet de montrer un équipement ou une ressource sans le déposer au sol.
