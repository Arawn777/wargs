PlanBuild

Prépare les plans et organise le chantier. Une construction ne devient pas gratuite parce que tu l’as dessinée avec conviction.

Les commandes utiles

Fin : catalogue · F5 : mode · Maj / Ctrl / Alt + molette : gestes selon l’outil

Retrouver tous les raccourcis ↗

Mode d’emploi

Ouvre le catalogue avec Fin. Choisis l’outil du mod pour préparer ou placer un plan. Suis les indications de l’outil pour la rotation, le déplacement et les matériaux.

Ce que ça change

Prépare des plans, copie des constructions et utilise les outils de terrain. Le totem de chantier peut regrouper les matériaux pour achever les plans. Suis les indications de l’outil actif pour les gestes de placement.

Les règles du monde

Un plan sert à préparer la construction ; les matériaux restent à fournir. Le totem de chantier aide à les regrouper pour terminer le projet.

Planifier puis construire

Place un projet pour choisir le volume et l’emplacement avant d’investir tous les matériaux. La préparation du plan et son achèvement sont deux étapes différentes.

Avant de modifier le terrain

Vérifie l’outil et le mode affichés. Les gestes de molette et les modificateurs changent de rôle selon l’outil : ne suppose pas qu’un geste de rotation fera la même chose partout.
