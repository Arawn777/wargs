RtDQuestForge : les 109 quêtes du pack

7 packs, 109 identifiants uniques, aucun prérequis manquant ni cycle. Le paquet installé porte la version 0.2.14 dans son dossier et son manifeste. La DLL annonce toutefois 0.2.13 dans sa déclaration de plugin, comme le fichier de configuration. Les règles ont été lues dans cette DLL précise, sans supposer un changement de comportement à partir du nom du paquet. Les valeurs de quêtes sont celles du pack local : sur un serveur, les définitions transmises par le serveur font autorité.

Compteurs et validation

Pour une cible : nouveau compteur = min(quantité demandée, ancien compteur + quantité créditée). Les compteurs sont séparés par quête et par type d’objectif. Validation = tous les objectifs de mort atteints ET tous les objectifs de collecte atteints. L’ajout au sac doit réussir pour être compté. La validation ne retire aucun objet de collecte. Une quête terminée ne redevient pas disponible.

Compétences, dans le moteur installé : gain d’accumulateur = montant de SkillRewards × facteur des effets de progression × pas de progression de la compétence × taux global de gain. Seuil du niveau suivant = 0,5 × floor(niveau + 1)^1,5 + 0,5. Seuils indicatifs : niveau 0 → 1 ; niveau 10 → environ 18,74 ; niveau 50 → environ 182,61. Si le seuil est franchi, le moteur de base gagne un niveau, remet l’accumulateur à zéro et ne distribue pas le surplus en plusieurs niveaux dans cet appel. D’autres modifications du moteur peuvent influer sur le gain. Ces montants sont donc indiqués comme entraînement, pas comme niveaux garantis.

Distribution des récompenses et sauvegarde

À la validation, le mod marque d’abord la quête terminée, puis tente de distribuer les récompenses. Un objet inconnu ou sans composant d’objet est ignoré avec un avertissement. Le chemin de sac plein appelle DropItem sur l’objet qui n’a pas pu entrer ; le moteur exige de pouvoir retirer cet objet de l’inventaire avant de le poser, ce qui peut faire échouer ce secours. C’est une analyse du code installé, pas un test destructif de tes récompenses : garde des cases libres. Les progressions locales sont indexées par nom de personnage, sans identifiant de monde dans le nom de sauvegarde. Elles ne sont pas examinées ni modifiées pour ce guide.
