La mémoire des gestes

Les raccourcis WARGS

Clavier AZERTY, commandes de souris et combinaisons : retrouve rapidement l’action que tu cherches.

La marche automatique utilise bien ², à gauche du 1. La planche dessine ce symbole comme un « 2 ». Les commandes ci-dessous précisent les contextes et incluent les actions de souris.

13 groupes de commandes

Déplacements & pouvoirs

  • ² : marche automatique.
  • A AZERTY : pouvoir A de demi-dieu.
  • Verr. Maj : pouvoir B de demi-dieu.
  • Blocage + A : pouvoir C ; blocage + Verr. Maj : pouvoir D.
  • Alt gauche : attaque spéciale habituelle à la place de celle du demi-dieu.

Journal & coopération

  • L : journal de quêtes.
  • O : fenêtre sociale.
  • I : fenêtre de groupe.

Inventaire & rangement

  • Avec le coffre ouvert : B pour empiler, N pour se réapprovisionner, K pour trier.
  • Alt + clic sur un objet : gérer ses favoris.
  • Alt + Z / X / C : emplacements rapides 1 / 2 / 3, une fois débloqués.
  • Alt + 1 / 2 / 3, sur la rangée supérieure : munitions.
  • Alt + Q / E / R : nourriture.
  • Alt + glisser le panneau d’équipement : déplacer ce panneau.

RecipePinner

  • Clic molette sur une recette ou pièce : épingler.
  • Maj + clic molette : réduire ou retirer.
  • F7 : afficher ou masquer les recettes.
  • F9 : afficher ou masquer la liste de collecte.
  • Début : page suivante.
  • Suppr deux fois en moins de 2 secondes : effacer toutes les recettes épinglées.

Plantation & récolte

  • Ctrl droit + flèches droite / gauche : plus / moins de colonnes.
  • Ctrl droit + flèches haut / bas : plus / moins de lignes.
  • Maj + récolte : récolter en groupe le même type de ressource.
  • F8 : activer ou désactiver PlantEasily.
  • F10 : activer ou désactiver l’accrochage.

Gizmo • marteau

  • Maj + rotation : axe X.
  • Alt + rotation : axe Z.
  • Y : remettre l’axe choisi à zéro.
  • F6 : changer de mode de rotation.
  • P : sélectionner la pièce visée.
  • Page ↑ / Page ↓ : ajuster la finesse des angles.

PlanBuild

  • Fin : ouvrir le catalogue de plans.
  • F4 : changer de mode sur les outils qui le proposent.
  • Molette, Maj, Ctrl et Alt : rotation, déplacements ou rayon selon l’outil ; suivre son aide affichée.

Bouclier & balistes

  • Clic molette sur une arme à une main : exclure du bouclier automatique ; une croix rouge apparaît.
  • Maj + E sur une baliste : changer de mode de ciblage.

Plongée

  • S’accroupir : descendre.
  • Sauter : remonter.
  • Courir : accélérer.
  • À la surface : récupérer de l’endurance.

Contenants visibles

  • Maj + E sur un tonnelet Mead Hall : prendre rapidement des potions.
  • P en visant un contenant Muji qui le propose : personnaliser l’apparence.
  • Les gestes changent avec la cible visée ; au marteau, P peut aussi sélectionner une pièce avec Gizmo.

Herbes & pipe

  • Clic droit sur un bourgeon, ou glisser sur le mortier : charger.
  • Mortier équipé + clic gauche : commencer le broyage.
  • Clic droit pendant le broyage : annuler et conserver l’avancement.
  • Maj + clic droit sur le mortier : éjecter un bourgeon non commencé.
  • Clic droit sur une herbe moulue : charger la pipe.
  • Clic droit sur la pipe chargée : fumer.
  • Maj + clic droit sur une pipe pleine : éjecter la charge.

Apparence, chat & préférences

  • Inventaire ouvert + T : panneau Transmog.
  • Ctrl droit + clic sur un objet : partager son lien dans le chat.
  • Ctrl gauche + Alt gauche : inspecter le chat et libérer le curseur.
  • F1 : préférences des mods.
  • Ctrl gauche + F1 : restaurer la position et la taille du panneau.
  • Maj gauche + F1 : restaurer son échelle.

Boutiques

  • Double-clic sur un article : choisir la quantité.
  • Alt + glisser : déplacer la boutique ou le panneau de quantité.
